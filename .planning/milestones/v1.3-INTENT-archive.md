## Business Model Pivot (confirmed by user)

AIDEAS is a **productized service** — not pure SaaS, not consultancy.
- Setup fee + monthly subscription, cancel anytime
- Human delivery, portal monitoring
- Pricing anchor: "more affordable and less problematic than an employee" (~$60-80K CAD/year benchmark in Ontario)
- Stripe deferred until customer 5+ — manual invoicing / e-Transfer to start

## Target Customer (validated through 10+ conversations)

- Owner-operator of white-collar business in Ontario (Canada)
- 2-30 employees, $500K-10M CAD revenue
- Post-survival, stuck under $10M ceiling
- Tight margins; next hire is a $60-80K bet they can't recoup quickly
- Mix of (a) owners of professional firms (legal, accounting, consulting) and (c) C-level of SMBs (CEO/COO)
- Validated pain: *"sé que la IA es el futuro pero no sé cómo enfrentarlo"* (not "tengo tareas repetitivas")
- 0 paying customers as of milestone start

## The Core Insight That Drives v1.3

The current AIDEAS portal is locked behind login — visitors must register to see anything. This kills:
- SEO and organic traffic
- Pre-signup interest validation
- Lead capture at moment of maximum intent

**v1.3 inverts this:** The catalog becomes the lead-generation funnel. Anonymous browsing, scenario selection, ROI calculation, then email capture at peak intent.

## Customer Flow (10 steps)

1. Lands on public landing (Factory.ai style)
2. Clicks "Ver qué puedo automatizar"
3. Browses 7 functional areas at `/catalog`
4. Marks scenarios that apply (pain-language checkboxes)
5. Sees personalized plan with ROI calculation ("= $X CAD of employee cost")
6. Enters email to receive plan
7. Receives email with plan + schedule-call CTA
8. Fills pre-call context form (4-5 structured questions, NOT a chat)
9. Schedules call
10. Enriched lead appears in existing admin dashboard

## Catalog Structure (KEY data model change)

Current: 66 templates organized technically (categories, industries) — locked behind login
Target: 50 client-language scenarios mapped to 135 n8n templates, organized by 7 **functional areas** (NOT industries):

1. Ventas (4 scenarios, ~6 templates)
2. Marketing (10 scenarios, ~35 templates) — RICHEST
3. Atención al Cliente (9 scenarios, ~30 templates) — RICHEST
4. Documentos (6 scenarios, ~15 templates)
5. Productividad (11 scenarios, ~25 templates)
6. Reportes (3 scenarios, ~4 templates) — WEAKEST, requires custom investment
7. Agentes IA (4 scenarios, ~12 templates)
8. Integraciones & Seguridad (3 scenarios, ~6 templates)

Source: github.com/enescingoz/awesome-n8n-templates + custom mappings.
User has already prepared the full scenario list with pain-language phrasing.

## Visual Style: Factory.ai Reference

User chose **Factory.ai design system** as visual guide:
- Light theme (#eeeeee background, #fafafa cards)
- Geist Sans + Geist Mono typography (already in Next.js stack)
- Code Orange accent (#ef6f2e) — single accent color only
- No shadows, no gradients — borders and typography drive hierarchy
- Border radius: 4px buttons, 6px cards, 0px header
- "Technical brutalism meets digital precision" aesthetic
- Section gap 72px, card padding 16px

This REPLACES the current OKLCH dark-first theme.

## Scope Decision: Option 2 (chosen by user)

User chose **scope option 2**: new public surfaces + reskin of BOTH existing dashboards.

In scope:
- Design system migration (OKLCH → Factory tokens)
- Catalog data model rework (functional_areas + scenarios + scenario_templates pivot)
- Scenario content seeding (50 scenarios, mapped templates, pain copy)
- Public landing page (SSR, SEO, no login)
- Public catalog navigation (SSR, no login)
- Scenario selector + ROI calculator
- Email capture + pre-call context form (form, NOT chat)
- Lead enrichment into existing admin
- Reskin customer dashboard (7 sections)
- Reskin admin dashboard (5 sections)
- Resolve carry-over: dark mode toggle + language switcher in admin shell

Out of scope (deferred):
- Stripe integration (manual cobro until customer 5)
- AI conversational chat (replaced with structured form)
- New automation features (no DIY builder)

## Technical Decisions

- NO external templates imported (Aigocy, Aixor, DesignPro all evaluated and rejected for Bootstrap conflicts)
- Build natively in existing Next.js 16 + Tailwind 4 + shadcn stack
- Use shadcn blocks + Magic UI + Aceternity for pre-built sections if needed
- Framer Motion for animations (not GSAP/AOS)
- All public pages MUST be SSR for SEO
- Light mode default; dark mode optional support
- Maintain i18n EN/ES parity (Ontario primary = EN)
