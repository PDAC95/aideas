1. **FaqAccordion** (`web/src/components/landing/faq-accordion.tsx`) — Client Component (`"use client"`):
   Use the native `<details>`/`<summary>` element rather than a JS-managed accordion. Native `<details>` ships fully collapsed but the answer content is ALWAYS in the SSR HTML (search-engine indexable), with toggle behavior built into the browser — no JS needed for open/close, but a small `useState` hook is fine if Patrick wants animation. Simplest implementation:
   ```tsx
   "use client";
   import { ChevronDown } from "lucide-react";

   type Faq = { question: string; answer: string };

   export function FaqAccordion({ items }: { items: Faq[] }) {
     return (
       <div className="max-w-3xl mx-auto divide-y divide-border border-y border-border">
         {items.map((item, i) => (
           <details key={i} className="group py-4 px-2">
             <summary className="flex items-center justify-between cursor-pointer list-none font-medium text-base lg:text-lg">
               <span>{item.question}</span>
               <ChevronDown className="h-5 w-5 text-muted-foreground transition-transform group-open:rotate-180" aria-hidden="true" />
             </summary>
             <p className="mt-3 text-muted-foreground leading-relaxed">{item.answer}</p>
           </details>
         ))}
       </div>
     );
   }
   ```
   Rationale:
   - `<details>` is fully accessible by default (keyboard, screen reader), no ARIA required
   - Closed-by-default visually but `<p>{answer}</p>` is in the SSR HTML — Google + Bing index it
   - `group-open:rotate-180` is a Tailwind utility that targets the `open` attribute on the parent `<details>`

   ```tsx
   const QUESTION_KEYS = ["q1", "q2", "q3", "q4", "q5", "q6"] as const;

   export async function FaqSection() {
     const t = await getTranslations("landing.faq");
     const tq = await getTranslations("landing.faq.questions");
     const items = QUESTION_KEYS.map((k) => ({
       question: tq(`${k}.question`),
       answer: tq(`${k}.answer`),
     }));

     return (
       <section className="py-20 container mx-auto px-4">
         <header className="max-w-2xl mx-auto text-center mb-12">
           <h2 className="text-3xl lg:text-4xl font-bold">{t("title")}</h2>
           <p className="mt-4 text-muted-foreground">{t("subtitle")}</p>
         </header>
         <FaqAccordion items={items} />
       </section>
     );
   }
   ```
   Notes:
   - The Server Component resolves the 6 question/answer strings server-side and passes them as a prop to the Client accordion → SSR HTML contains all 12 strings → SEO-indexable
