<objective>
Reskin the 5 existing shadcn primitives (button, card, input, form, label) to consume the Factory tokens shipped in Plan 25-01. This is the load-bearing reskin — every consumer in the codebase already imports these primitives, so swapping their CVA variant classes propagates Factory styling across the app for free.

Purpose: Land the Factory radius scale (4px buttons, 6px cards), the "no decorative shadows" rule, and the Code Orange focus ring on every primitive. Mitigates Pitfall 1 (white-card-on-white-bg) by baking `border border-border` into the Card root so consumers can drop `shadow-sm` later without losing card visibility.

Output:
- `button.tsx` with `rounded-sm`, no shadow, accent default variant.
- `card.tsx` with `rounded-md`, `border border-border`, no shadow, tighter padding (`gap-4 p-6`).
- `input.tsx` with no shadow, `focus-visible:ring-2 ring-ring ring-offset-2`.
- `form.tsx` and `label.tsx` verified to consume `--destructive` and `--foreground` (likely no edits needed; defensive read).
</objective>
