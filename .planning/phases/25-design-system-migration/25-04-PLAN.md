<objective>
Eliminate all `purple-*` Tailwind literals and hardcoded purple/pink HEX values across the codebase, swapping them to Factory's Code Orange via the `--primary` token. Without this plan, the visual identity does not change — Plan 25-02 reskins primitives but the 56 files using `bg-purple-600` directly stay purple.

Purpose: Land the brand identity flip (purple → Code Orange) across every "branded" surface (active tabs, focus rings, CTAs, top-automation callout). Also clean up the lone gradient (`top-automation-card.tsx`) and the 4-5 hardcoded `#a855f7` Recharts fills (Tier 6 in research) — the chart fixes are deliberately one-line edits, not full ChartContainer migrations (that's Phase 32).

Output:
- Every `purple-*` Tailwind utility replaced with the equivalent semantic token (`primary`, `accent`, `ring`, `destructive`).
- `top-automation-card.tsx` gradient removed, replaced with `bg-primary text-primary-foreground` (research Open Question 3 recommendation).
- 4 Recharts components have `fill="#a855f7"` swapped to `fill="#ef6f2e"` (and any inline tooltip border `#e5e7eb` swapped to `#d6d3d2`).
- Zero brand-color leaks remain in `web/src`.
</objective>
