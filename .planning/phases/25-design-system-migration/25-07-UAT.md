1. Page bg is light gray (#eeeeee) in light, near-black (#020202) in dark.
2. Cards have visible 1px border (no `bg-card` cards disappearing into bg).
3. Buttons that should be CTAs are Code Orange (#ef6f2e) with white text.
4. Active tabs / nav items have Code Orange underline or tinted bg.
5. No purple or pink anywhere.
6. Body text legible (warm-gray on light, light-gray on dark) — AA contrast.
7. Tables, forms, modals not visually broken (no overflow, no clipped content).
8. Recharts bars on /dashboard/reports are orange.
9. ADMIN badge in /admin/* header is Code Orange.
10. /admin/login is intentionally dark (Factory near-black bg, Code Orange CTA).
