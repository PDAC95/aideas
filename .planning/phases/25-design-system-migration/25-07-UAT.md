## Failures Logged

Two NEEDS-FIX entries surfaced during UAT on the customer dashboard shell. Both were fixed in-phase per the CONTEXT.md UAT-blocking rule before declaring PASSED.

### Failure 1 — Customer dashboard header surface mismatch

- **Route:** `/dashboard` (and every customer dashboard child route — shared `<header>` shell)
- **Dimension:** All locales × all viewports (light + dark)
- **What broke:** `dashboard-header.tsx` shipped with `bg-card` (Factory `--card` token = `#fafafa` light / `#101010` dark). Against the new `bg-background` page surface (`#eeeeee` light / `#020202` dark) the header rendered as a visually distinct white strip at the top of every dashboard route — broke the unified shell aesthetic Plan 25-06 was supposed to deliver.
- **Decision:** In-phase fix (UAT-blocking — header is the most-seen surface in the customer app, cannot ship with a visible seam against the page bg).
- **Fix:** `bg-card` → `bg-background` on the `<header>` element. Border-bottom (`border-b border-border`) retained as the structural separator (matches Factory no-decorative-shadow rule, Plan 25-06 decision).
- **File:** `web/src/components/dashboard/dashboard-header.tsx`
- **Commit:** `34e3f32` — `fix(25-07): unify customer header background with page bg`
- **Verification:** Browser refresh confirmed header now blends seamlessly into page bg across light + dark + EN/ES; build re-ran clean (exit 0).

### Failure 2 — Customer dashboard layout wrapper still on Tailwind literal

- **Route:** `/dashboard` (and every customer dashboard child route — shared `(dashboard)/layout.tsx` wrapper)
- **Dimension:** All locales × all viewports (light only, dark unaffected)
- **What broke:** After Failure 1 fix, header + page bg still mismatched in light mode. Root cause: the `(dashboard)/layout.tsx` wrapper div was still on the Phase 24 Tailwind literal `bg-gray-200 dark:bg-gray-900` instead of the Factory token. Plan 25-06 reskinned the admin wrapper (`bg-gray-100 dark:bg-gray-950 → bg-background`) but missed the customer wrapper.
- **Decision:** In-phase fix (UAT-blocking — Plan 25-06 scope was "cross-cutting layout shells", and missing the customer wrapper was a Plan 25-06 leftover bug, not new scope).
- **Fix:** `bg-gray-200 dark:bg-gray-900` → `bg-background` on the wrapper div. Final unification of customer dashboard shell under Factory `--background` token.
- **File:** `web/src/app/(dashboard)/layout.tsx`
- **Commit:** `b40d0fa` — `fix(25-07): migrate dashboard layout wrapper to bg-background token`
- **Verification:** Browser refresh confirmed customer dashboard shell now fully unified under `--background` across header, page wrapper, and main content area in both light and dark modes; build re-ran clean (exit 0).
