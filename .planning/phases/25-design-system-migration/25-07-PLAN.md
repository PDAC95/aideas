Quality bar (interim — Plan 25-04/25-06 do not pretend to fully reskin every screen):
- PASSED: Screen renders without layout overflow, all text is legible at AA contrast, no color regressions (no purple leaks, no orange-on-white invisible text), interactive states (hover, focus, active) are visible and consistent.
- NEEDS-FIX (in-phase): Screen has a clear regression (overflow, invisible card, broken button color, illegible text) — fix in this plan.
- DEFERRED-TO-32/33: Screen is "unpolished but functional" — the composed component still uses shadow-sm or bg-white but text is legible, layout is intact, no color regressions. Logged for Phase 32/33 with the specific component identified.
